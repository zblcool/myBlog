## 1. 核心定位与商业结论

Ashmartisan 的核心产品不只是 3D Viewer，而是面向工业设备制造商的 **Interactive Product Explainer / Sales Enablement Solution**：将 CAD / 3D 模型转化为客户能够自主探索、销售人员能够讲解、展会现场能够演示的互动产品体验。

核心使用场景：

- **Trade Show / Exhibition**：在展台屏幕上展示大型或不便运输的设备，支持触控、自动循环、离线运行、QR Code 分享与询盘。
- **Website**：将交互式产品展示嵌入制造商官网，辅助潜在买家理解结构、配置和功能。
- **Sales Team**：在笔记本、平板和客户会议中替代部分沉重实物样机、静态图片和 PDF 讲解。

**商业判断：** 三种场景不宜开发成三套独立产品。应复用统一技术底座，并通过不同部署模式、授权范围和服务内容形成套餐。

**销售价值主张：** One build for your website, your sales team and your stand.

## 2. 目标客户与市场切入

优先考虑 Brisbane、Queensland 及澳洲其他地区的中小型工业设备制造商、矿业设备供应商、机械与自动化设备企业。优先筛选产品复杂、价值较高、运输不便、已有参展或销售演示需求、缺少内部实时 3D 开发能力的公司。

潜在客户通常已经拥有展会营销、产品宣传、销售工具或网站更新预算。Ashmartisan 的切入点不是让客户为新奇 3D 技术单独申请预算，而是让既有投入获得更高复用价值。

对于单次展会预算约 A$20,000–50,000 的制造商，A$3,000–6,000 的展示项目可能值得讨论，但绝不是自动可获批的小额支出。必须结合项目价值、预算负责人和采购周期判断。

## 4. 推荐收入结构：一次开发 + 多场景授权 + 持续服务

1. **Core Product Experience / Development Fee**：一次性的模型准备、交互配置、动画、品牌化、测试与交付。
2. **Usage Licence**：按单场展会、年度展会、网站部署、销售团队使用等场景约定使用范围和期限。
3. **Ongoing Services**：托管、维护、支持、内容更新、新产品接入、定制功能及集成。

**开发费与授权费不应混淆。** 客户获得已交付版本的长期使用权，不意味着 Ashmartisan 需要永久免费托管、修复所有未来兼容性问题或持续开发新功能。

## 5. 三档 V1 套餐与报价假设

### 5.1 Exhibition Pilot — A$1,500–2,500

**定位：** 首次参展、希望以较低投入验证交互式展示价值的中小型制造商。

建议包含：

- 最多 3 个由客户提供、符合技术要求的 3D 模型（用于同一场展会）。
- 基础品牌化、零件热点和预设视角。
- 自动循环展示的 Kiosk Mode。
- 单场展会使用授权，最长约 7 天。
- 展会开始前的评审与修订（对外不强调“几轮”，具体轮次在合同中约定）。
- 基础 QR Code 分享。

不包含：从零建模、复杂机械动画、现场技术支持、硬件租赁、持续官网部署及大量模型清理。

### 5.2 Product Experience — A$4,500–7,500

**定位：主力产品。** 适合希望长期在官网及销售流程中使用交互式展示的制造商。

建议包含：

- 最多 10 个工业设备产品及合理范围内的基础模型优化。
- 多零件热点、说明、技术参数与询价入口。
- 按模型适用性提供 X-ray、Section、Exploded View。
- 预设动画或引导式讲解流程。
- **网站嵌入**（作为客户现有页面中的一个模块）及销售演示模式。
- 展会 Kiosk 模式（自动循环、离线运行、QR Code），不另收单场授权费。
- 客户品牌 UI；评审与修订直到客户验收，并含上线后的持续支持（对外不写“几轮”，具体评审轮次、支持期限与范围在合同中约定）。
- 已交付版本的长期使用授权。

持续托管、更新、复杂运动学、额外产品和特殊集成另行报价。

### 5.3 Complete Sales & Exhibition — A$8,000–15,000+

**定位：** 跨展会、官网和销售团队统一使用的高价值项目。

建议包含：

- 产品数量超出 Product Experience 上限（10 个）或范围更大的项目，按范围报价。
- 高级机械运动与引导式演示。
- Website、Sales、Kiosk 三种模式。
- 离线包、QR Code、访客互动分析。
- 询盘表单及基础数据流转。
- 展前部署测试、约定范围内的远程支持。
- 品牌化及适用的多语言内容。

CRM 深度集成、现场支持、额外硬件、复杂模型处理和新增需求单独计费。

**商业重点：** 以 Product Experience 为主要收入产品；Exhibition Pilot 降低首次采购门槛；Complete Package 提升复杂项目的客单价。

## 6. 免费试用与设计合作客户策略

免费策略可以保留，但**不应向每位陌生潜在客户承诺完整免费定制开发**。

### 6.1 免费定制 Preview：用于主动获客

- 利用公开且可合法使用的产品资料，或经授权使用的模型。
- 提供少量交互功能，例如一个产品视角和两三个热点。
- 使用 Ashmartisan 托管的私人演示链接。
- 明确为 Concept Preview，不作为正式生产交付。
- 内部投入尽量控制在约 1–3 小时；超过限额须重新评估。

### 6.2 免费 Exhibition Pilot：仅针对精选客户

初期可选择最多约 2–3 家目标匹配度高、能够提供真实展会验证和反馈的设计合作客户。

合作前明确：

| 条款 | 建议安排 |
|---|---|
| 期限 | 一场展会，最长约 7 天 |
| 范围 | 一个产品、固定功能清单 |
| 资产 | 客户提供并授权使用 |
| 品牌 | Powered by Ashmartisan |
| 反馈 | 展会后复盘 |
| 案例使用 | 客户批准后方可公开品牌、照片和项目资料 |
| 商业路径 | 试用前明确后续正式报价或价格区间 |
| 责任 | 明确硬件、网络、部署和故障处理责任 |

免费试点的目标是获得真实验证、可信案例和后续付费机会，而不是无条件提供免费软件。不能把客户在展会上使用一次当作未来必然成交的证据。

**推荐对外表达：**

> The pilot is complimentary. If you'd like to continue using the experience on your website or at future exhibitions, we can offer a permanent licence or an extended exhibition package.

## 7. 展会授权、续用与长期升级

> V1.1 说明：Product Experience 已包含展会 Kiosk 模式。以下 Event Licence 机制适用于“先从单场展会开始”的客户，以及不购买 Product Experience、只按场次使用的情况。

不建议采用“三次展会之后自动终身免费”的简单规则。它容易把有限收入变成无限维护预期。

更建议采用 **Event Licence + Upgrade Credit**：

| 阶段 | 示例收费 | 权益 |
|---|---:|---|
| 精选客户首次试点 | $0 | 最多 7 天、限定功能 |
| 首次正式展会 | $1,800 | 已配置体验、单场使用 |
| 第二次展会 | $1,200 | 同一产品、同一版本复用 |
| 长期授权升级标准价 | $3,000 | 网站与销售团队长期使用 |

**抵扣示例：** 客户已支付 $1,800 + $1,200；如果给予 $1,500 的升级抵扣，则再付 $1,500 即可获得长期授权，累计支出 $4,500。

这些数字属于示例机制，需要与套餐价格和实际交付范围协调，避免重复收费或报价冲突。

### 年度 Exhibition Pass

对于一年参加多场展会的客户，可测试 **A$2,500–4,000 / year** 的年度展会授权，前提是客户已经拥有可运行的产品体验。约定适用产品、设备数量、组织范围和标准支持内容。

不必一开始强迫客户订阅。可先通过一次性项目成交，再根据复用频率和服务需求验证年度收费的合理性。

## 8. 渠道伙伴与展台承包商合作

存在两种不同合作模式，不能混淆。

| 条款 | Referral Partner | White-label Reseller |
|---|---|---|
| 客户销售 | Ashmartisan | 展台承包商 |
| 与终端客户签约 | Ashmartisan | 承包商 |
| 最终报价决定权 | Ashmartisan | 承包商 |
| 客户管理 | Ashmartisan | 承包商 |
| 建议测试分成 | 成交额 10%–15% | 给渠道约 20%–30% 折扣 |
| 适合情况 | 偶尔介绍客户 | 稳定合作、打包销售 |

以最终售价 A$6,000 为例：

- **Referral 12%**：伙伴获得 $720，Ashmartisan 获得 $5,280（尚未扣交付成本）。
- **Reseller 25% discount**：渠道向 Ashmartisan 支付 $4,500；若其以 $6,000 售出，价差为 $1,500（尚未扣渠道成本）。

建议初期优先 Referral Model，以便直接接触制造商、学习需求并建立案例。交付流程成熟后，再对稳定渠道开放 White-label Reseller。

品牌策略：免费或折扣试点默认保留 Powered by Ashmartisan；正式直客项目可依套餐移除；White-label 合作按独立授权及商业条款处理。

## 9. 交付成本、毛利与报价底线

应区分：

- **Reusable Platform Development**：已经投入、可以跨客户复用的核心软件研发。
- **Per-client Delivery Cost**：每位客户新增的模型处理、内容、动画、品牌适配、测试、部署和支持。

标准项目示例工时：

| 工作项 | 假设工时 |
|---|---:|
| 需求沟通 | 3h |
| CAD / 3D 模型处理 | 8h |
| 产品热点与说明 | 5h |
| 动画与交互适配 | 8h |
| 品牌 UI 与部署 | 4h |
| QA、修改、培训 | 6h |
| **总计** | **34h** |

以内部目标时薪 A$85/h、其他直接成本 A$200、项目报价 A$5,500 计算：

- 计价劳动成本：34 × $85 = **$2,890**。
- 直接交付成本：$2,890 + $200 = **$3,090**。
- 扣除计价劳动及直接成本后的贡献利润：$5,500 − $3,090 = **$2,410**。
- 贡献利润率：$2,410 / $5,500 ≈ **43.8%**。
- 达到 40% 贡献利润率的理论报价：$3,090 / 0.6 = **$5,150**。

这不是税后净利润；尚未扣除获客、管理、保险、持续平台研发等间接成本。模型复杂度及返工风险会显著改变结果。

**关键原则：** 即使由创始人亲自交付，也要为劳动设定内部成本；不能把自己的时间当作零成本。免费试点同样属于营销投资。

## 11. 授权、知识产权与技术边界

- **离线授权**：Kiosk 离线运行时应允许可靠的预签发授权，提前测试设备时间异常、重装和过期情况；不能因为授权服务器不可达导致展会现场停摆。
- **技术限制不是唯一保障**：展会授权需要合同使用范围与合理技术限制配合。
- **客户资产**：客户保留原始 CAD、品牌和产品资料的相关权利，并保证向 Ashmartisan 提供所需授权。
- **平台知识产权**：Ashmartisan 保留通用软件框架、可复用组件及预先存在的知识产权，除非合同另有明确约定。
- **交付许可**：客户获得约定范围内的已交付版本使用许可，不自动获得源码所有权、转售权或无限新功能开发。
- **服务边界**：持续托管、维护、技术支持、内容更新和新功能需明确期限与费用。
- **公开案例**：使用客户名称、产品模型、展会照片或数据前需取得相应许可。

以上属于商业条款设计建议，正式合同应结合澳洲法律和实际业务结构审核。

## 13. 标准直客销售流程

1. **研究目标公司**：选择本地制造商，了解产品、现有网站、参展历史和潜在销售展示问题。
2. **展示有限定制 Preview**：先用小范围交互 Demo 建立理解和兴趣。
3. **确认实际使用场景**：下一场展会、长期官网部署、销售团队，或多场景复用。
4. **确认资产和范围**：现有 CAD / STEP / GLB、零件数量、机械动画、热点、内容审核、设备与离线要求。
5. **提供两个明确选项**：单场 Exhibition Pilot 与长期 Product Experience，而非过多组合。
6. **提出升级抵扣**：展会投入可在约定条件下部分抵扣长期授权费用。
7. **确认商务细节**：决策人、预算、交付日期、付款节点、修改轮次、验收标准和支持责任。

**推荐英文销售表达：**

> We offer two ways to get started.
>
> If you're preparing for an upcoming exhibition, we can create a focused interactive experience for that event, without requiring a large upfront commitment.
>
> Alternatively, we can build a permanent product experience that your team can use across your website, sales presentations, and future exhibitions.
>
> And if you start with an exhibition package, part of that investment can be credited towards a permanent solution.
>
> The idea is to start with what you need today and expand as you see the value.

## 15. 后续验证与迭代重点

当前所有价格应作为 **Pricing Hypotheses** 管理，利用首批真实客户持续校准：

- 标准客户从获得模型到可交付，需要多少真实工时。
- CAD / STEP / GLB 的质量差异会造成多少额外工作。
- 哪些功能是客户必须购买的，哪些只是演示时看起来吸引人。
- 客户更愿意购买单场展会、长期使用还是年度授权。
- 单次项目是否有足够贡献利润覆盖获客和未来研发。
- 免费 Preview 和免费 Pilot 是否带来有效会议、报价及付费项目。
- 代理渠道是否能持续带来客户，折扣后利润是否仍然合理。
